DotMop · 点点净隐私政策

点点净在 Mac 上本地扫描和清理外置磁盘。应用没有账号、广告、遥测或跟踪功能。应用不会将你的文件、磁盘信息、扫描结果或操作记录发送给开发者或第三方。

商店版首次扫描前会请求你选择外置磁盘，并可在本机保存安全范围书签，以便再次访问该卷。偏好、扫描索引和操作记录保存在本机。操作记录可能包含磁盘名称、文件路径、错误原因或恢复文件夹位置，可在应用的「设置 → 操作记录」中清除。用户发起清理时，恢复文件夹和清单会写入所选外置卷，供之后恢复使用。

如需联系开发者，可通过 GitHub 仓库的 Issues 页面。Issues 是公开的，请勿附上私人文件名或磁盘路径。

DotMop Privacy Policy

DotMop scans and cleans external drives locally on your Mac. The app has no accounts, advertising, telemetry, or tracking. It does not send your files, drive information, scan results, or activity logs to the developer or third parties.

The App Store build asks you to select an external drive before scanning it. It may save a security-scoped bookmark on your Mac to access that volume again. Preferences, scan indexes, and activity logs stay on your Mac. Activity logs can contain drive names, file paths, errors, or recovery folder locations. You can clear them from Settings → Activity Log. When you request cleanup, DotMop writes a recovery folder and index to the selected drive when needed for file recovery.

You can contact the developer through the project's GitHub Issues page. Issues are public. Avoid including private file names or drive paths.
